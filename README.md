# Lorenz-System---Computational-Study-of-Lyapunov-Exponent-
A small computational physics engine written in C++ for simulating nonlinear dynamical systems. The project currently implements the Lorenz system using a fourth-order Runge–Kutta (RK4) integrator and explores chaotic behavior through trajectory divergence and numerical estimation of the largest Lyapunov exponent.
